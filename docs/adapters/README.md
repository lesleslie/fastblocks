# FastBlocks adapters

Adapter documentation index. Each entry links to the per-adapter
guide for the four in-scope adapters (templates, style, icons,
fonts); other adapters live under `fastblocks/adapters/<name>/README.md`.

| Adapter | Guide | Module |
|---|---|---|
| Templates | [templates.md](templates.md) | `fastblocks/adapters/templates/` |
| Style | [style.md](style.md) | `fastblocks/adapters/style/` |
| Icons | [icons.md](icons.md) | `fastblocks/adapters/icons/` |
| Fonts | [fonts.md](fonts.md) | `fastblocks/adapters/fonts/` |

For adapters outside the audit scope (app, auth, admin, routes,
sitemap, images), see the corresponding
`fastblocks/adapters/<name>/README.md` files in the source tree.
